# LinkedIn (manual)

No API auto-poster here (the Share/Posts API requires a partner-approved app). Post manually.

## How to post
1. Native video upload performs best. For long talks, a short highlight clip + link works too.
2. Post text = a professional framing of `{title}`/`{summary}` — lead with why the audience
   should care. Put the watch link in the post or first comment.
3. Add 3–5 topical hashtags from `{hashtags}`.
