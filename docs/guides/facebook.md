# Facebook (manual)

No API auto-poster here (Graph API posting needs a Page, a long-lived Page token, and app
review). Post manually.

## How to post
1. Upload the video natively to your Page/Profile (native uploads outrank shared links).
2. Post text = `{title}` + `{summary}`; the watch link can go in the first comment to avoid
   link down-ranking.
3. Add captions: upload the target-language SRT as a caption track in the video editor.

## From the checklist
Reuse the queued `{title}`/`{summary}`; adapt tone for a Facebook audience.
