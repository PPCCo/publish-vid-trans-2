# Instagram (manual)

No API auto-poster here (Instagram's Graph API requires a Business/Creator account, a linked
Facebook Page, and app review — out of scope for automation). Post manually.

## How to post
1. Instagram is vertical-video first. For Reels, prepare a 9:16 crop of a highlight clip (use the
   framework's selection/clip feature to cut a short segment, then reframe in your editor).
2. Feed posts allow a longer video; captions go in the post text — paste the `{title}` +
   `{summary}` and put the full link in your bio (in-caption links aren't clickable).
3. Add relevant hashtags from `{hashtags}`.

## From the checklist
Use the queued `{title}`/`{summary}` as the caption; adapt length for Instagram.
