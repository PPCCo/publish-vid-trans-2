# TikTok (manual)

No API auto-poster here (the Content Posting API requires an approved developer app and an
audited use case). Post manually.

## How to post
1. TikTok is short vertical (9:16). Cut a compelling ≤60–180s highlight with the framework's
   clip/selection feature, reframe to 9:16 in your editor.
2. Caption = a tight hook from `{title}`/`{summary}`; add 3–5 hashtags from `{hashtags}`.
3. Put the full watch link in your profile bio (in-caption links aren't tappable).
4. Burn-in captions help — export the target-language SRT and overlay.

## From the checklist
Use the queued `{title}`/`{summary}` as the caption seed; trim to a punchy hook.
