# Rumble (manual)

No API auto-poster here. Upload through the Rumble web UI.

## How to upload
1. **Upload → select the final video** at `projects/<id>/outputs/<lang>/dubbed-video.mp4`
   (the exact file bound in `platform-package.json`).
2. Title = `{title}`; description = `{description}` (includes the chapter list).
3. Add the target-language captions (SRT from `outputs/<lang>/captions.<lang>.srt`).
4. Choose visibility and licensing/rights options per your rights record.

## From the checklist
Reuse the platform-package `{title}`/`{description}` verbatim — they're already assembled.
